# anatomy-reveal

- Repo: https://github.com/annnguyentt/anatomy-reveal-skill
- Penulis: Ann Nguyen
- Lisensi: MIT
- Skill: `SKILL.md` (di root repo)

Bangun objek fisik apa pun sebagai figur isometrik "anatomy" dari banyak
bagian kecil, lalu jadikan (1) halaman diseksi interaktif yang bisa
diseret/diputar/dibongkar dan (2) film product-reveal (MP4, 9:16/4:5/1:1/16:9,
30 fps, 10 detik default, 3–60 detik). `template/` adalah proyek kerja
lengkap (contoh: mesin espresso, 82 bagian). Butuh Node.js 20+, Chrome,
ffmpeg, ImageMagick 7.

## Clone

```bash
git clone https://github.com/annnguyentt/anatomy-reveal-skill
```

Skill ini tidak di-vendor di repo ini — clone langsung dari upstream supaya
selalu dapat versi terbaru.
