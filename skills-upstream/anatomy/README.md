# anatomy

- Repo: https://github.com/wheresryan22/anatomy
- Penulis: Ryan
- Lisensi: MIT
- Skill: `SKILL.md` (di root repo)

Gambar isometrik interaktif yang menjelaskan ide teknis sebagai benda fisik
nyata (dial gauge, arcade cabinet, mesin roket, ripple tank, dan lain-lain):
banyak bagian kecil presisi, shading empat nada, urutan gambar yang benar,
plus shader WebGL (api, air, cahaya). 8 contoh lengkap ikut dalam repo.
Butuh Node.js 20.10+ dan Chrome/Chromium untuk pengecekan.

Repo upstream 40 MB (mayoritas `examples/` 25 MB) — tidak di-vendor di sini.

## Clone

```bash
git clone https://github.com/wheresryan22/anatomy
```
