# Skill Upstream — link-only

Skill-skill dari repo lain TIDAK di-vendor di repo ini. Alasannya:

- tetap di tangan pembuatnya (lisensi + update terbaru langsung dari upstream),
- beberapa repo besar (anatomy 40 MB, hairline 12 MB) dan berisi kode executable —
  clone langsung dari repo aslinya lebih aman dan lebih ringan.

Tiap folder berisi README.md dengan deskripsi singkat, link GitHub, lisensi,
dan perintah clone. Jalankan clone-nya kalau mau pakai skill itu.
